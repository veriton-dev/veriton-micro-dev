Auth-review checklist

  • Cost too low (<10) on internet-facing logins → flag HIGH.
  • Cost so high it DoS’s your auth workers under burst → flag MED (queue/rate-limit).
  • Truncation bugs (bcrypt secret >72 bytes silently ignored) → flag HIGH for long passphrases.
  • Wrong identifier ($2a$ vs $2b$ null-byte edge cases in old libs) → note compatibility.
  • Missing pepper is OK; missing rate limit + lockout is not.
  • Reversible “encryption” of passwords or MD5/SHA1-only stores → CRITICAL.
