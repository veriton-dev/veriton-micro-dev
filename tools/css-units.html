UnitValueNotes

How relative units resolve

  • rem = relative to root font-size (defaults 16px).
  • em / % (font-size context) = relative to parent font-size.
  • vw/vh/vmin/vmax = % of viewport width/height/min/max.
  • Absolute: 1in = 96px, 1cm = 96/2.54 px, 1pt = 1/72 in, 1pc = 12pt (CSS reference pixel).
  • This tool treats bare % as font-size percent of parent (layout % of containing block needs a width context you set via parent).
