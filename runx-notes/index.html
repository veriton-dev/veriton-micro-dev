Veriton notes: installing runx CLI 0.9.0

runx is a governed runtime for portable agent skills. Skills publish as SKILL.md packages; the CLI admits acts under explicit authority and seals receipts. Upstream repo: github.com/runxhq/runx. Catalog: runx.ai/x.

Why this note exists

We run metered extraction APIs for agents (x402 on Base). Evaluating runx as the execution boundary under OpenClaw means we need a reproducible install path on Linux without guessing package names.

Install that worked here (2026-09-11)

npm i -g @runxhq/cli
runx --version
# → runx-cli 0.9.0

Alternate installer from upstream docs: curl -fsSL https://runx.ai/install | sh. Do not install the unrelated legacy npm package named bare runx (2016 job runner) — wrong tool.

First commands after install

runx --help
runx doctor --json
runx registry search crm --json
# first-party skill exists: runx/crm-cleanup

What we care about as operators

  • Receipt-sealed dogfood runs (auditable before payout rails).
  • Catalog publish via runx registry publish after runx login --provider github --for publish.
  • Harness + verify loop for skills that touch CRM/write transports.
